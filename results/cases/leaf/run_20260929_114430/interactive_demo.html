砂轮可行中心交互演示

根部线上的离散采样点均可点击。单位：。红色候选为可行中心，灰色候选为碰撞筛除中心。

根部线投影：点击橙色采样点

蓝线：root_line；橙色点：可点击采样点；红色点：当前选中点。编号从 0 开始，按分支顺序拼接。

当前点的局部法平面放大图

黑线：rho=r；蓝色虚线：rho=r-delta；红点：可行中心；灰色叉号：不可行中心；橙色粗线：外半径可行圆弧。
局部坐标：横向正方向为 +b1，纵向正方向为 +b2。生成逻辑：先取根部线切线 t 和与 t 最不平行的参考轴 q，计算 b1=normalize(t×q)，再计算 b2=normalize(t×b1)。候选径向方向为 e(theta)=cos(theta)b1+sin(theta)b2。
