## 1. 当前碰撞检测流程

1. 对每个 root 采样点，先估计局部表面法向 `n_i`；
2. 由曲线切线 `t_i` 与 `n_i` 建立切平面；
3. 在切平面内生成候选中心方向 `e(theta)`，候选中心 `x_i + rho e`；
4. 沿砂轮轴向 `a=n_i` 移动 `width/2`：`c = x_i + rho e + (width/2) a`；
5. 对每个固定姿态，用 AABB 宽相 + 三角形连续窄相判断三角形与有限圆柱是否相交；
6. 允许目标接触/接触斑时，把“浅穿透 + 法向接近端面 + 目标 patch 内”的相交标为可行；
7. 对可行候选，再用封闭网格中心射线检查砂轮是否整体在工件内部。

当前默认配置：
- `r=0.02`、`width=0.004`、`delta=0.001`（normalized units）；
- `candidate_angles=180`、`radial_samples=3`（pipeline 默认）；
- `contact_patch_enabled=true`；
- `contact_patch_radius=2r=0.04`；
- `max_contact_penetration=0.025r=0.0005`；
- `contact_patch_normal_tolerance=30°`；
- `allow_target_contact=true`。

## 2. 当前切平面到底怎么选？

### 2.1 结论：当前是“单点锚定 + patch 估计法向”，不是多点的平面拟合

当前实现：

1. `root_line` 采样点 `x_i`；
2. 用局部 face patch（多面）估计 `n_i`；
3. 曲线切线 `t_i` 投影到 `n_i` 的切平面；
4. `q_i = n_i × t_i`；
5. 切平面为过 `x_i`、由 `t_i` 和 `q_i` 张成的平面；
6. 候选中心：
   ```text
   c = x_i + rho * e_i(theta) + (w/2) * n_i
   e_i(theta) = cos(theta) t_i + sin(theta) q_i
   ```
7. 砂轮近端面经过 `x_i + rho e_i`；因为 `e_i ⟂ n_i`，所以该端面与过 `x_i` 的切平面共面。

因此：

- **几何锚定方式更接近图 (a)**：切平面只经过一个 root 点 `x_i`；
- **法向来源是 patch**：`n_i` 由多个局部面估计（平均/拟合/折边平分线），不是来自单个三角形；
- 它不是图 (b) 的“用一个平面拟合多个 mesh 点，然后把砂轮端面放在该拟合平面上”。

更准确地说：

> 当前是“图 (a) 的单点切平面锚定 + 图 (b) 式的多面法向估计”的混合方案。

### 2.2 砂轮中心与 h/2

你的记忆基本正确：

- 砂轮中心在切平面内的偏移是 `rho e_i`；
- 再沿法向移动 `h/2 = width/2`；
- 所以中心到切平面的法向距离是 `h/2`，同时还有切平面内的 `rho` 偏移。

但要注意：

- **近端面**与切平面共面；
- 中心不一定在目标点正上方，而是在切平面内偏移 `rho`；
- 对 `rho=r`，目标点在端面边缘；对 `rho<r`，目标点在端面内部。

## 3. 为什么“不考虑豁免”时砂轮会嵌入？

这里有两个层次，必须分开。

### 3.1 最重要：平端面圆柱与平面接触是“面接触”，不是球头的“点接触”

图示 (a) 画的是曲面与切平面在一个点相切；这更接近**球头刀**的几何。

但当前工具是**平端面实心圆柱**：

- 近端面是一个平面圆盘；
- 如果工件表面也是平面，端面平面与工件平面**共面**；
- 两者的交集是一个二维区域，不是单点；
- 三角面-圆柱判定会把该共面区域判为相交。

因此：

> 即使法向完全正确、切平面严格相切，平端面砂轮在“端面贴住平面”的姿态下也必然与工件表面有面积重叠。  
> 如果不允许接触，那么所有端面贴面的候选都会被判为碰撞，**没有任何可行姿态**。

这也解释了为什么全量结果中几乎所有绿色都是 `contact_patch_only` 或 `target_contact_only`，而没有 `safe`。

如果希望“无豁免也无碰撞”，必须：

- 让近端面离开工件一个 clearance（沿法向抬升）；
- 或只允许目标面接触；
- 或把工具模型改成球头/圆角端面；
- 或把“目标面接触”定义为允许状态，而不是碰撞。

### 3.2 如果法向/切平面不准确，会额外造成真实穿透

即使把端面接触视为允许，以下原因仍会造成**非目标区域**的穿透：

1. **patch 法向不是该点的精确法向**  
   当前法向由多个局部面平均/拟合/折边得到。曲面、倒角、棱边、局部翻转、三角形不均匀都会让平均法向偏离真实切平面；切平面绕单点旋转后，会切入附近表面。

2. **法向符号朝内**  
   如果 `n_i` 指向工件内部，砂轮中心沿 `+h/2 n_i` 会向材料内部移动；近端面虽然经过目标点，但圆柱体会进入工件。  
   这需要确认当前 P1/baseline 的 flash 定向、patch 平均和边缘法向是否始终朝外。

3. **root 点不在真实表面上**  
   `root_line` 是飞边/工件根部交线，采样点可能落在三角面附近但不严格在曲面上；切平面经过该点，可能与真实表面有偏移。

4. **棱边/凹棱处不存在单一支撑平面**  
   凸棱可以用法向锥内的平面支撑；凹棱或两个面夹角大于 180° 时，单一平面无法同时支撑两侧，端面平面必然切入一侧。

5. **局部网格是离散面片，不是光滑曲面**  
   即使底层几何是凸曲面，用平均法向建立的平面也可能切过邻近三角面；尤其 patch 跨面、跨倒角时。

6. **patch 跨越两个表面**  
   如果 patch 同时包含底面和侧壁，平均/拟合法向会落在两个面之间；切平面可能同时切入两个面。当前 P1 已尝试用 normal clustering/crease gate 处理，但仍可能残留。

7. **接触斑阈值/穿透深度计算误差**  
   当前 `penetration` 使用裁剪多边形的**顶点**径向来估计，可能低估真实穿透；这会把实际穿透误判为“浅接触”。

8. **砂轮半径/厚度与局部曲率**  
   平面端面在局部曲面上的支撑只在切点附近成立；当砂轮半径较大、表面曲率较大或存在窄槽时，端面外缘仍可能碰到邻近表面。

9. **rho 偏移**  
   中心在切平面内偏移 `rho`，端面圆盘覆盖目标点周围区域；如果该区域内表面不是同一平面，就会接触/穿透。

### 3.3 如果是图 (b) 的多点拟合平面

如果做法是：

- 取多个 mesh 点/三角形；
- 拟合一个平面；
- 把砂轮端面放在该拟合平面上；
- 再沿法向抬 `h/2`；

那么对**凸曲面**，拟合平面通常是弦平面，位于曲面下方/内部；曲面会鼓出到平面之上，端面放在该平面上会切入曲面。  
这正是你担心的“中心比理论值更靠近平面/嵌入”。

**直接由飞边-工件交点建立切平面**也有类似问题：

- root line 给出的是**交线/切线方向**，不是曲面法向；
- 多个交线点拟合平面会得到弦平面，不是切平面；
- 在棱边处，交线两侧面可能不同，单一平面不能同时支撑两侧；
- 正确做法应是：在一个 root 点用**该点局部单侧面的法向**（或凸棱的支撑法向锥）建立过该点的切平面，而不是用多个点拟合平面后直接当接触平面。

因此：**图 (b) 不适合直接作为砂轮端面平面**；如果要用多点信息，最多用来估计法向，然后必须重新锚定到单个 root 点。

## 4. 碰撞检测中已发现的问题

### 4.1 高影响：可行语义是“允许接触”，不是“无碰撞”

P1 全量 29,880 个候选：

| reason | count |
|---|---:|
| `contact_patch_only` | 26,439 |
| `target_contact_only` | 485 |
| `triangle_interior_collision` | 2,048 |
| `cylinder_cap_collision` | 908 |
| `safe` | 0 |

P1 的 26,924 个“可行” = 26,439 + 485；**没有一个是真正的 `safe`**。  
baseline 同样是 26,929 = 26,597 + 332，也没有 `safe`。

因此绿色中心只能解释为：

> “允许目标/接触斑的浅接触”，不是“砂轮没有进入工件”。

### 4.2 高影响：穿透深度可能被低估

`cylinder_exact.py:254-264`：

```python
axial_penetration = max(axial_coords + width/2)
radial_penetration = max(radius - radial_coords)
penetration = min(axial_penetration, radial_penetration)
```

`radial_coords` 只取裁剪多边形**顶点**；如果三角形内部穿过轴线或最近点在边/内部，`R - rho` 会低估真实径向穿透。

合成例子：
- R=0.02、w=0.004；
- 三角形平面在近端面内约 0.0006；
- 顶点半径约 0.0195；
- 真实穿透深度约 0.0006；
- 程序计算约 0.0005；
- 在 `max_contact_penetration=0.0005` 时会被接触/目标接触路径接受。

这会导致“浅接触”阈值被绕过。

### 4.3 高影响：目标接触/接触斑过于宽松

当前允许：

- 目标 witness 在 `target_contact_tolerance=1e-4` 内；
- 或任意同向三角形在 `contact_patch_radius=2r=0.04` 内；
- 穿透 ≤ 0.0005；
- 法向与轴夹角 ≤ 30°。

没有要求必须是目标面/目标根部面。  
对于平端面砂轮，2r 的 patch 会覆盖整个端面，绿色可能包含目标附近的非目标面接触。

### 4.4 中高影响：clearance / nearest_distance 不是实际值

`cylinder_exact.py:751-752`：

```python
nearest_distance = np.where(feasible, inf, 0.0)
clearance = np.where(feasible, inf, -clearance)
```

- 不可行候选的 `nearest_distance` 恒为 0；
- `clearance` 恒为 `-clearance`（当前 0）；
- 不是真实间隙或穿透深度；
- `contact_max_penetration` 对目标接触路径没有记录实际深度。

### 4.5 中高影响：半径选择使用近似包络

`pipeline.py:482` 的半径扫描使用 `check_candidates`（球形包络、忽略朝向），最终结果用精确三角形-圆柱。  
两者可能不一致：近似扫描选出的半径，在精确碰撞下覆盖率可能不足。

### 4.6 中影响：三 OBJ 候选集与 pipeline 不一致

三 OBJ/P1 full 使用：

- 72 角度；
- 每点只生成 `rho=r` 一层；
- 没有 `delta` 的径向层。

pipeline 默认：

- 180 角度；
- `radial_samples=3`；
- `delta=0.001`。

因此 `circle_feasible_center_domains.obj` 只是外圈 `rho=r` 的代表性结果，不是完整 `[r-delta,r]` 中心域。

### 4.7 中影响：角度可行域是离散采样

固定姿态的三角形/圆柱判定是连续的，但候选角度是离散的（72/180）。  
`feasible_angle_intervals_degree` 只是离散角度填充，不是连续角度证明；相邻采样角之间没有边界二分。

### 4.8 中影响：内部包含测试单射线

`_point_inside_closed_mesh_vectorized`：

- 单固定方向射线；
- 全 500,000 三角形扫描；
- 用 `round(distance,10)` 去重后奇偶；
- 未做多射线投票。

可能受射线穿过边/顶点影响，且性能很差。

### 4.9 已正确/基本可靠的部分

- `cylinder_aabb` 投影半径公式正确；
- AABB 宽相保守；
- 三角形轴向裁剪 + 横截面最近距离是连续的；
- 实心圆柱和平端面语义正确；
- 封闭网格中心包含检查存在；
- 目标接触豁免已加入深度/patch 约束；
- 43 个测试通过。
